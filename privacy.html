Security of Your Personal Data

The security of Your Personal Data is important to Us. PixelMentor implements the following security measures:

  • All data transmitted between the app and our servers is encrypted using HTTPS/TLS encryption
  • User authentication is handled by Supabase using industry standard JWT token authentication with ES256 encryption
  • Uploaded photos are stored securely and accessed only through time-limited presigned URLs expiring after 10 minutes
  • Database access is protected by Row Level Security ensuring users can only access their own data
  • All API endpoints require valid authentication tokens
  • Rate limiting is enforced to prevent unauthorised access and abuse
  • Real time error monitoring via Sentry detects and alerts on security incidents

In the event of a data breach affecting your personal information we will notify you within 72 hours of becoming aware of the breach in accordance with applicable privacy laws. While We strive to use commercially reasonable means to protect Your Personal Data, We cannot guarantee its absolute security.

PixelMentor uses artificial intelligence technology provided by OpenAI to power its core features including photo analysis, lesson content generation, AI tutor chat, and quiz questions.
